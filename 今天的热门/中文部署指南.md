## 🚀 快速部署

### 方式一：使用安装器（推荐）

```bash
# Linux/macOS
curl -fsSL https://openclaw.ai/install.sh | bash

# Windows PowerShell
iwr -useb https://openclaw.ai/install.ps1 | iex
```

### 方式二：从源码部署（当前 Codespace 环境）

```bash
# 进入项目目录
cd /home/codespace/.openclaw/workspace/今天的热门/openclaw-ai-assistant

# 安装依赖
npm install -g openclaw@latest

# 运行新手引导（选择中文）
openclaw onboard --install-daemon
```

### 方式三：Docker 部署

```bash
cd /home/codespace/.openclaw/workspace/今天的热门/openclaw-ai-assistant

# 使用 docker-compose 启动
docker-compose up -d
```

## 🌐 语言配置

### UI 界面语言

OpenClaw UI 支持以下语言：
- 🇨🇳 简体中文 (zh-CN)
- 🇹🇼 繁体中文 (zh-TW)
- 🇺🇸 英语 (en)
- 🇧🇷 葡萄牙语 (pt-BR)

#### 自动检测
UI 会根据浏览器语言自动选择：
- 浏览器语言为 `zh` 开头 → 自动使用简体中文
- 浏览器语言为 `zh-TW` 或 `zh-HK` → 自动使用繁体中文

#### 手动设置
在 UI 界面的设置中可以切换语言，或通过浏览器控制台：

```javascript
localStorage.setItem("openclaw.i18n.locale", "zh-CN");
location.reload();
```

### 助手回复语言

在 `SOUL.md` 或会话中指定回复语言。当前配置：

```markdown
# SOUL.md 中添加
- **回复语言：** 中文（简体）
```

## 🔧 常见问题

### Q1: UI 界面还是英文怎么办？

**解决方案：**
1. 检查浏览器语言设置，确保首选语言为中文
2. 清除浏览器缓存后刷新
3. 在浏览器控制台运行：
   ```javascript
   localStorage.setItem("openclaw.i18n.locale", "zh-CN");
   location.reload();
   ```

### Q2: 助手用英文回复怎么办？

**解决方案：**
在对话开始时明确指定：
```
请用中文回答我的问题
```

或在 `SOUL.md` 中添加永久性语言偏好。

### Q3: 中文文档找不到？

**解决方案：**
中文文档在项目目录的 `docs/zh-CN/` 文件夹中，可以在线阅读或本地查看。
